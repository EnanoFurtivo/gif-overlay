# CI runs overlay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bottom-right column on the top monitor showing every running GitHub Actions run of the configured repos, with elapsed time, an estimate from past runs and the result.

**Architecture:** Pure tracking/estimating logic in `gif_overlay/ci.py` (tested without GTK); a layer-shell view in `gif_overlay/ci_view.py` that fetches on a worker thread and draws like `agents_view.py`.

**Tech Stack:** Python 3, GTK3 + gtk-layer-shell via gi, cairo/Pango, urllib, GitHub REST API, `gh auth token`.

**Spec:** `docs/superpowers/specs/2026-11-03-ci-runs-design.md`

## Global Constraints

- Success tiles leave after 60 s; other conclusions after 600 s or when a newer run of the same workflow_id + head_branch appears.
- Estimate = median of the last 10 successful durations (same workflow + branch, else same workflow).
- Poll 10 s while active, 30 s idle; status lists `in_progress`, `queued`, `waiting`; `If-None-Match`.
- No network or `gh` call on the GTK thread.
- Tests: `python -I -B tests/test_ci.py` (same custom runner as the other test files).

## Review Focus

- A run rerun (same id, new attempt, new `run_started_at`) while its result tile is shown → it becomes active again with a fresh timer.
- A run that disappears from the active lists and whose fetch fails → stays as it was and is retried, never stuck as "running" forever after a later successful fetch.
- Offline / 401 / gh not logged in → logged once per streak, no crash, no busy loop.
- Timestamps missing (`run_started_at` null on a queued run) → `created_at` is used.
- Clock skew (now slightly before `run_started_at`) → elapsed never negative.

### Task 1: `gif_overlay/ci.py` — tracker, estimate, text

**Files:** Create `gif_overlay/ci.py`, `tests/test_ci.py`.

**Interfaces — Produces:**
- `parse_time(iso: str | None) -> float | None` (epoch seconds, `Z` suffix).
- `median_duration(history: list[dict], branch: str, n=10) -> float | None` — history = completed successful runs of ONE workflow, newest first.
- `class CiTracker(success_linger=60, other_linger=600)`:
  - `update(active: list[dict], now: float) -> list[int]` — the current active runs (all repos); returns ids of tracked-active runs missing from `active` (to fetch).
  - `finish(run: dict, now: float) -> bool` — a fetched run; if completed: becomes a result tile (True = newly finished, play sound); if still active: kept.
  - `forget(run_id)`.
  - `tiles(now) -> list[Tile]` newest-created last, expired results dropped. `Tile` fields: `run` (dict, includes `repo`), `finished_at` (None while active).
  - `is_active() -> bool`.
- `describe(tile, estimate: float | None, now: float, multi_repo=False) -> (caption, time_text, fraction | None, state)`; state ∈ `queued, waiting, running, over, success, failure, cancelled`.
